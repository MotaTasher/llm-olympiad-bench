Правила запусков

Правила запуска
моделей

  • Одно и то же условие и system prompt для всех моделей.
  • Только текст: без поиска, инструментов, кода и калькуляторов.
  • Один запуск на пару «задача × модель»; модели запускаются последовательно.
  • Температура 0,1 и максимальный reasoning-режим — там, где их поддерживает API.
  • Общий лимит — 128 000 output-токенов. GigaChat и Alice ограничены API до 8192 и 8000 токенов за запрос.
  • Стоимость считается по фактическим input/output-токенам. Ошибка одной модели не останавливает остальные и сохраняется в логе.
